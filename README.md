<h1>Challenge Amigo Secreto  </h1>

<h2>📌Descrição </h2>
  O objetivo deste desafio é fortalecer  habilidades em lógica de programação, utilizando JavaScript e HTML. 
 
   - Adicionar amigos a uma lista.
   - Exibir os nomes inseridos.
   - Sortear aleatoriamente um amigo.
   - Mostrar o resultado na tela.

## Objetivo do Desafio
  - Manipulação de arrays.
  - Estrutura de repetição (for).
  - Funções em JavaScript.
  - Manipulação DOM (querySelector, innerHTML, appendChild).
  
## Funcionalidades
  ✔️Adicionar nomes de amigos à lista.<br>
  ✔️ Exibir os nomes  no navegador.<br>
  ✔️ Validar entradas (não permitir nomes vazios).<br>
  ✔️ Sortear aleatoriamente um amigo da lista.<br>
  ✔️ Mostrar o resultado do sorteio.
